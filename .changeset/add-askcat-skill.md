Add the `askcat` skill (productivity bucket, user-invoked). A variant of `teach` narrowed to one topic: the skills the user has installed from this repo. It reads every installed `SKILL.md` (and the docs pages and `vibe/WORKFLOW.md` where present), then fills a bundled HTML template in which a cartoon cat guide walks through the kit chapter by chapter in the user's language: one card per skill with a plain-words one-liner, when to reach for it, what a run looks like, a realistic example prompt, the cat's one tip, and working / broken tells; a "which skill do I need?" decision tree; the first-run sequence; a glossary; search; and "I've tried this" ticks saved in the browser so the page doubles as a checklist. Every sentence must come from a file opened in the session; the skill never runs or installs anything.
